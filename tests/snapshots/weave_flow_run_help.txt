Run one saved API flow

Usage: infynon.exe weave flow run [OPTIONS] <ID>

Arguments:
  <ID>  

Options:
      --base-url <URL>   
      --set <KEY=VALUE>  
      --format <FORMAT>  
      --output <FORMAT>  
      --no-input         
  -h, --help             Print help

Examples:
  infynon weave flow run auth-refresh
  infynon weave flow run auth-refresh --format json --no-input
  infynon weave flow run auth-refresh --format junit --no-input

Exit codes:
  0   all assertions passed
  20  flow execution failed
  21  required runtime input missing in non-interactive mode
  22  invalid flow definition or missing node
